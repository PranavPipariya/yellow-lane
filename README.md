# Entropy Arcade

Provably-random arcade games ( mainly : Plinko + Spin Wheel) that **consume Pyth Entropy on-chain**.
Players connect a wallet on **Base Sepolia**, place a stake, and outcomes are decided by **Pyth Entropy** via callback to the game contract.

> ✅ Built for the **Pyth Entropy Pool Prize**: the app **consumes** random numbers generated by Pyth on-chain and documents how to run, deploy, and verify usage.

---

## Features

* **Pyth Entropy–backed randomness** (on-chain; no client randomness).
* **Plinko** and **Spin Wheel** UIs using the same on-chain payout curve.
* **USD-first UI**: Stake, fee, total, payout, and P&L shown in USD (with ETH hints).
* **Wallet connect** + **Base Sepolia** network gating.
* **Event-driven results**: UI waits for `BetSettled` event and shows the official outcome.

## Smart Contracts

* **Game**: `PlinkoEntropy.sol`
* **Deployed (Base Sepolia)**:

  * `PlinkoEntropy` at **`0x80ceC1F46fDcF8CA442c2994eF0B91939eA5adae`**
* **Pyth Entropy (Base Sepolia)**: **`0x41c9e39574F40Ad34c79f1C99B66A45eFB830d4c`** (contract calls this)
* **Callback**: `entropyCallback(uint64,address,bytes32)` (called by Pyth Entropy)

### How settlement works (high level)

1. Player calls `play(rows)` with `msg.value = stake + entropyFee`.
2. Contract calls Pyth Entropy `requestWithCallback(...)`.
3. Pyth Entropy later calls `entropyCallback(...)` with a verified random number.
4. Contract derives the bin/multiplier, pays out in ETH, and emits `BetSettled`.

## Setup

1. **Install**

```bash
pnpm install
```

2. **Environment**
   Create a `.env` with:

```bash
PRIVATE_KEY=0xYOUR_PRIVATE_KEY
BASE_SEPOLIA_RPC_URL=https://your-base-sepolia-rpc
ETHERSCAN_API_KEY=your_key_optional
```

3. **Hardhat v2 config**
   Make sure Hardhat uses **CJS** (to avoid ESM error HH19):

* File is named **`hardhat.config.cjs`** (not `.js` or `.ts`).

---

## Build & Deploy (contracts)

```bash
pnpm hardhat compile
pnpm hardhat run scripts/deploy.ts --network baseSepolia
```

You’ll see:

```
PlinkoEntropy deployed to: 0x...
Entropy fee (via contract) wei: 15000000000001
```

Copy the deployed **game address** into the UI:

* `src/components/games/Plinko.tsx` → `PLINKO_ADDR`
* `src/components/games/SpinWheel.tsx` → `PLINKO_ADDR`

---

## Fund the Contract

Winnings are paid from the contract, so top it up:

* From your wallet: send e.g. `0.05` Base Sepolia ETH to the contract address.
* Or via script:

```bash
pnpm hardhat run scripts/fund.ts --network baseSepolia
pnpm hardhat run scripts/balance.ts --network baseSepolia
```

## Run the App

```bash
pnpm dev
```

* Open the Home page → **Connect wallet** (button just connects; doesn’t navigate).
* Switch to **Base Sepolia** if prompted.
* Navigate to **/games/plinko** or **/games/spinwheel**.
* Set a stake, review **Entropy fee** + **Total**, then **Play (on-chain)**.
* The UI shows:

  * Tx link (BaseScan)
  * **Awaiting Pyth Entropy callback** (sequence number)
  * Final **bin**, **multiplier**, **payout**, and **P&L in USD** once `BetSettled` fires.

## Troubleshooting

* **HH19 ESM error**: rename `hardhat.config.js` → `hardhat.config.cjs`.
* **Empty call result (`0x`) just after deploy**: wait a couple confirmations or skip immediate reads in the deploy script.
* **Disabled Play button**: ensure wallet is connected, on **Base Sepolia**, `PLINKO_ADDR` is set, and `getCurrentFee()` is loading.
* **No payout**: confirm the contract has balance and that the callback fired (watch script / BaseScan events).
